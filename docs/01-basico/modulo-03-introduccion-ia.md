# Módulo 3: Introducción Práctica a la Inteligencia Artificial

**Nivel:** Básico  
**Duración estimada:** 6 horas prácticas  
**Objetivo:** Dominar la creación de prompts estructurados para acelerar investigación, guiones y copys manteniendo el criterio editorial humano.

## Framework de Prompt Estructurado (R-C-T-R-F)
1. **Rol:** define el perfil experto que debe asumir el modelo.
2. **Contexto:** industria, audiencia, tono de marca y objetivo de negocio.
3. **Tarea:** acción exacta que necesitas.
4. **Restricciones:** extensión, palabras a evitar, nivel técnico y verificación de datos.
5. **Formato:** tabla Markdown, lista accionable, guion por escenas o JSON.

## Buenas prácticas y ética
- Verifica siempre cifras, fechas y enlaces antes de publicar para evitar alucinaciones.
- Nunca pegues contraseñas, claves de API ni datos privados de clientes en herramientas sin políticas de privacidad adecuadas.
- Versiona tus mejores prompts en `plantillas/libreria-prompts-inicial.md` dentro de GitHub para reutilizarlos con clientes y alumnos.
